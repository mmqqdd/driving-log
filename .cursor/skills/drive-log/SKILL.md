# 记录驾考

用户通常只给一句话。从中判断类型，落到档案、科目笔记、日志三处，不要追问细节。

先读 `system/profile.md` 的 `profile` 区块，再动手。

## 工作流程

```
- [ ] 1. 判断这句话属于哪一类
- [ ] 2. 写或追加 journal/YYYY-MM-DD.md（练车 / 刷题时）
- [ ] 3. 回写对应科目：科一进 subjects/k1/ 那一节（必要时兼写 kemu1.md）；科二三四仍写 subjects/kemuN.md
- [ ] 4. 需要时更新 profile
- [ ] 5. 日记加 `doing`（日历上那两个字）。日历会自己出现，不用改 journal/index.md
```

### 1. 分类

| 用户的话 | 类型 | 落到哪 |
|---|---|---|
| 今天练了 XX / 入库压线 / 坡道熄火 | 练车 | journal + 对应科目失败点 / 口诀 |
| 这题又错了 / 黄灯那题 / 科目一 90 分 | 刷题 | journal（可简）+ `subjects/k1/` 对应课；原题压缩进 `kemu1.md` |
| 教练说 / 看点是 / 打到底再回半圈 | 口诀 | 对应科目的「教练口诀 / 手感」 |
| 约了科目二 / 科目一过了 | 进度 | `system/profile.md` |
| 我在杭州考 C1，刚开始科目一 | 档案 | `system/profile.md` |

一句话里可以同时有几类，都做。没提日期就用今天。没提科目就按 `profile.current` 推断，并在回复里点一句假设。

**科目映射**

- 倒车入库、侧方停车、坡道、直角、曲线、库 → kemu2（`subjects/kemu2.md`）
- 灯光、靠边、加减挡、直线行驶、路口语音 → kemu3
- 题库、选项、满分 100、90 过 → 科目一：回写 `subjects/k1/` 对应课，不要只写旧的 `kemu1.md`；已过科目一之后的题库默认 kemu4
- 明确说了「科目一/二/三/四」以用户为准

科一小节怎么对：

| 题在说什么 | 回写 |
|---|---|
| 约考、候考厅、交卷、考第二次 | `k1/01-shangchang.md` 考试须知 |
| 记分 12/9/6/3/1 | `k1/02-jifen.md` 违法记分 |
| 超速、超员、超重、疲劳 | `k1/03-chao.md` |
| 限速、停车距离、能见度、故障标志 | `k1/04-xiansu.md` |
| 标志、标线、警告禁令 | `k1/05-biaozhi.md` |
| 灯、手势、仪表、英文缩写 | `k1/06-deng.md` |

能对上原子的，顺手补 `kb/atoms/k1.json`（用户当场纠正的数字以用户为准）。

**状态从语气推断**，不要反过来问：

| 用户的话 | mood |
|---|---|
| 一次过 / 稳了 / 手感有了 | 5 |
| 比上次好 / 基本能进 | 4 |
| 还行 / 练了几次 | 3 |
| 压线、扫库、熄火、挂科 | 3，问题写进失败点 |
| 完全没感觉 / 越练越差 | 2 |

### 2. 写日志

路径 `journal/YYYY-MM-DD.md`。当天已有就往后接段落，不要覆盖。

写成**能讲给朋友听的故事**，不要「怎么样 / 记下来」这种标题，不要条目备忘录。数字和规矩嵌进句子里。用户丢来的**官方材料**（流程图、价目表）可以放到 `public/images/`，用 `![说明](/images/文件名)` 插在对应段落旁边。**聊天截图不要上网页**；销售、教练、同学的真名不要写进站点，用「驾校」「教练」即可。

```markdown
---
title: 9 月 3 日 · 倒车入库扫库了
date: 2026-09-03
kind: practice
subject: kemu2
doing: 练车
items: [倒车入库]
---

# 9 月 3 日 · 倒车入库扫库了

今天去大兴练倒车入库。右库后视镜对上线才打方向，晚了半秒，扫到库角。
下次镜子刚对上线就打。
```

标题用「X 月 X 日 · 发生了什么」，不要「YYYY-MM-DD 周X」。
`kind`：`practice` 练车 · `quiz` 刷题 · `exam` 上场考试 · `note` 流程 / 聊天。
`items` 用项目名，不要空着。

只改档案、只记口诀、没有「今天练了 / 刷了 / 发生了」时，可以不写日志。流程类的新认知（约考规矩、地点）补进 `journal/process.md`，不要只堆在日记里。

### 3. 回写科目笔记

科一打开 `subjects/k1/` 对应那一节，把新规矩嵌进正文（保持一页尽量不超过两屏）。App 里错过的原题压成一句，追加到 `subjects/kemu1.md` 的易错，不要只写旧的 `kemu1.md` 然后不管课。

科二三四仍打开 `subjects/kemuN.md`。原来是 `- _（还没有）_` 的占位，用第一条真实记录替换掉。这些页留文件、不上导航。

**练车失败点**（追加，不要删旧的）：

```markdown
- **YYYY-MM-DD** —— 现象。原因。下次具体怎么改。
```

要可执行：不要写「下次注意点」，要写「右后视镜刚看到库角就回正，比这次早半秒」。

**教练口诀 / 手感**：写成「看哪里 → 做什么 → 做到什么程度」。和已有口诀冲突时，**以用户这次说的为准**，旧的改成「旧：…（已被教练纠正）」。

**易错题**（科目一 / 四）：

```markdown
- **题意一句话** —— 正确答案。你为什么会错。容易和哪题混。
```

同一题已存在就只补原因，不新建条目。

### 4. 更新档案

只在用户明确提到时改 `system/profile.md` 的 frontmatter：

- 过了某科：加入 `passed`，`current` 改下一科
- 约考：`exam_dates.kemuN` 写成 `YYYY-MM-DD`
- 驾校 / 教练 / 城市 / C1 或 C2：写入对应字段；C2 时 `transmission` 改成 `自动`

正文进度清单的勾选和 `passed` 保持一致。

### 5. 日历上的两个字

日记 frontmatter 写 `doing`：报名、听课、刷题、练车、约考、上场。日常页日历会自己出现这一天，不用改 `journal/index.md`。约了考试、还没上场：考试那天先建日期文件，`doing: 上场`，`when: "8:30"`（必须加引号），日历会标出时间。

网站分两块：**教学**（课程 / 练习 / 考试；科一在 `k1/`，科二三四在 `kemuN.md`）和 **日常**（`journal/`）。教学正文不写驾校品牌。新内容对号入座，不要写回首页长文。

## 例子

**输入**

> 今天练倒车入库，右库后视镜对上线才打方向，扫到库角了

**三处改动**

1. 新建 `journal/2026-09-03.md`，写成一段故事，不要「怎么样」「记下来」
2. `subjects/kemu2.md` 倒车入库失败点加「右库：后视镜刚对上线就打，再晚会扫库」
3. 若还在科目一，把 `profile.current` 改成 `kemu2`

**科一刷题输入**

> 黄灯那题又错了，没过线我还想抢

回写 `subjects/k1/07-rangxing.md`（黄灯没过线停在线外），并在 `subjects/kemu1.md` 易错加一句。不要只改旧的 `kemu1-guide.md`。

**对话里回复**：一句话确认记好了 + 针对这次失败的一条具体改法。不要复述整篇。

## 不要做的事

- 不要追问「打了几圈方向盘」「离合抬到哪」。用户没说就不要编数字。
- 不要用网上的通用场地尺寸覆盖用户或教练给出的看点。
- 不要把整道题库题干抄进笔记。题意压缩成一句。
- 地基信息（城市、C1/C2、当前科目）完全未知时，只问**一个**最有用的问题，不要连珠炮。
