# 5. 交通标志与标线

黄三角 = 警告。红圈 = 禁止。蓝 = 指示 / 指路。黑杠 = 解除。限速：**红高、蓝低、黑解除**。

**8 停 3 减**：八边形必须停。倒三角减速让，不是停死。路面画倒三角或「停」字，意思一样。

**禁令**：没杠 = 禁止通行。一道白杠 = 禁止驶入。蓝底一斜杠 = 禁长停。蓝底叉 = 停都不行。

**警告爱混**：黄底人 ≠ 人行横道（蓝斑马线）。黄底小孩 ≠ 学校。黄底自行车 ≠ 非机动车道。一个拱是驼峰桥，两个包是路面不平。铲土是施工。火车头是铁路，三道红杠大约 150 米。黄底车掉进水是**堤坝路**：路就在坝顶上，一边或两边掉下去就是水。口诀「水来土掩」。**沿河路不是这块标的名字。** 沿河只是路边有河、路还在岸上；国标警告标没有「沿河路」「傍水路」，看见水就选沿河，是错的。漫水路是水漫到路面上，要先停车看水情，也不是这块标。黄底船上有车是**渡口**：车开上船，摆到对岸接着开。**码头不是这块标的名字。** 码头是船停靠装卸的，国标警告标没有「码头」。

**标线**：白虚可变道，白实不能跨。路缘黄虚禁长停，黄实停都不行。中间两条黄虚是潮汐车道。入口标线「左进右出」。

新标：车道减少、线形诱导改成黄底警告。牌子背面不做广告。
