# 4. 灯、标志、手势

**标志颜色**

- 黄三角：注意 / 警告
- 红圈：禁止
- 蓝：指示、指路
- 黑杠：解除限制

**8 停 3 减**：八边形「停」= 必须停车让行。倒三角「让」= 减速让行，不是停死。弯道：一急、二反、三连续。会车让行：箭头「谁胖谁先走」，粗箭头优先。

**交警手**

- 左手举过头顶 → 停车等待
- 两臂平伸成一条线 → 直行
- 右手从上往下挥 → 减速慢行
- 哪边脸朝你，就往哪边指；哪只手摆，往哪边转
- 右手上举、左手摆 → 靠边停车
- 掌心对着你 → 停；胳膊平伸 → 直行

**车上的灯和表**

- 光束画成水平射出 = 远光；斜着射向地面 = 近光
- 前雾灯绿，后雾灯黄
- 夜间会车改近光
- 仪表 `(!)`：制动系统异常；`(P)`：手刹

英文缩写常考制动和预警：EBA / EBD / AEB 都跟制动有关；FCW 前碰预警；LDW 车道偏离；ACC / CCS 巡航；BSD 盲点；ESP 车身稳定。
