# 4. 灯、标志、手势

**标志颜色**

- 黄三角：注意 / 警告
- 红圈：禁止
- 蓝：指示、指路
- 黑杠：解除限制

**8 停 3 减**：八边形「停」= 必须停车让行。倒三角「让」= 减速让行，不是停死。

**交警手**

- 左手举过头顶 → 停车等待
- 两臂平伸成一条线 → 直行
- 右手从上往下挥 → 减速慢行

**车上的灯**

- 光束画成水平射出 = 远光；斜着射向地面 = 近光
- 前雾灯绿，后雾灯黄
- 夜间会车改近光
