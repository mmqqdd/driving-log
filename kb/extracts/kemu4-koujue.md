# 科目四口诀（社区提炼）

科四和科一共用一批灯光、手势、文明驾驶题。上场不一样：50 题，含多选。

## 上场

原件「温馨提醒」：50 题，单选 20 + 判断 20 + 多选 10，每题 2 分，100 分 90 过。东方时尚流程也是 50 / 90、路考过了不用约。题型拆分以当场电脑为准。

## 文明驾驶（意思对，不是看字）

选更安全的那句：减速、靠右、低速、停车、观察、礼让、依次、主动让行、确认安全。

通常不选：急、猛、持续紧跟、抢行、加速、尽快、迅速、立即（「立即报警」除外）、ABS 能缩短制动距离。

故障 → 开危险报警闪光灯并设警告。夜间 / 能见度低 → 近光，不是远光硬开。临时停车 → 危险报警闪光灯；雾天或夜间再加示廓灯、后位灯。长时间停进停车场。

## 灯光

- 近光常常是对的；只写「开远光」常常是错的
- 超车、路口、会车未关远光：用远近光交替，不是一直远光
- 环岛：进岛不打灯，出岛打右灯
- 雾天：雾灯 + 危险报警闪光灯
- 离开路口打右灯（社区说法，以现场标线为准）

## 多选（社区规律，先当参考）

「四种原则 / 四个信号灯 / 四个大货车 / 倒车 / 出车」这类常是全选。图里两辆公交、A 车 B 车也常全选。问「错误做法」时，「停车让行」往往是对的，不要当错项勾。两头牛不选「驱赶」，两头驴不选「警示并加速」。

「李某不选疲劳超员」这种按人名蒙题，不收。

## 行人 / 天气 / 动物

- 对向远光不关：减速或停车让
- 雨天打伞穿雨衣、冬天戴厚帽：提前喇叭，把速度降下来
- 行人扛家具：大距离，盯着他的方向
- 羊群过马路、牲口窜出来：减速，必要就停
- 人力车留距离；畜力车远处喇叭再减速
