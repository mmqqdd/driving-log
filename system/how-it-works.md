# 这套笔记怎么用

> 目标：**把从报名到拿证怎么学、怎么走，写清楚。**

## 一、它由四部分组成

```
学习路线  ──┐
驾考档案  ──┼──►  知道自己现在在哪、下一步学什么
科目大纲  ──┤
全过程日志 ─┘
    ▲
    └────────── 说一句就记下来
```

| 部分 | 是什么 | 谁来维护 |
|---|---|---|
| [学习路线](/system/route) | 四科怎么排、每天怎么学 | 你说，AI 写 |
| [驾考档案](/system/profile) | 驾校、车型、当前科目、约考日期 | 你说一句，AI 写 |
| [科目笔记](/subjects/) | 课程大纲、复习大纲、口诀、易错、失败点 | AI 写，你补细节 |
| [全过程日志](/journal/) | 练车、刷题、约考、过科 | AI 记，你说一句就行 |

## 二、日常怎么跑

### 场景 0：说学习路线 / 大纲

> 科目一我先看视频过一遍交规和标志，再每天刷 100 题，错的单独记

写进 [学习路线](/system/route)，并在 [科目一](/subjects/kemu1) 落成课程大纲和复习大纲。以你自己的节奏为准，不用网上的通用课表。

### 场景 1：练完车

> 今天练倒车入库，右库后视镜对上线就打方向，打晚了会扫库

AI 会：

1. 在 `journal/` 生成当天日志
2. 把这条手感和失败点写回 [科目二](/subjects/kemu2) 的倒车入库
3. 需要的话更新档案里的当前科目

### 场景 2：刷题错了

> 科目一又错了：黄灯亮时已经过停止线，可以继续通过

AI 会把题意、正确答案、你为什么会错，追加到 [科目一](/subjects/kemu1) 的易错里。同一题再错，只补原因，不重复建条目。

### 场景 3：教练随口说了一句

> 教练说坡道起步离合抬到车身微微抖就停住，先看后视镜再给油

写进对应项目的「教练口诀」，并标清看哪里、做到什么程度。网上的通用口诀如果和教练冲突，以教练 / 你当场的手感为准。

### 场景 4：约了考试

> 下周三上午科目二

更新 [档案](/system/profile) 的考试日期。

## 三、不要记什么

- 不要把整本驾考题库抄进来。只记**你错过的**和**你会混的**。
- 不要记「注意安全」这种空话。没有具体看点、数字或失败现象的句子，不配进笔记。
- 不要用网上的通用尺寸覆盖你驾校场地的数字。
